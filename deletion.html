Controle dos dados

Como excluir dados e encerrar o acesso

Estas instruções se aplicam à instalação local do Ads Ops Hub.

1. Interrompa o aplicativo

Encerre a sessão do cliente de IA e o processo do servidor MCP antes de remover credenciais da configuração local.

2. Remova ou revogue a credencial

Remova o perfil correspondente do arquivo privado de credenciais utilizado na instalação. O recurso de exclusão de tokens de uma implantação com login OAuth não substitui essa etapa para os perfis locais.

Revogue também a autorização ou o token nos controles da Meta apropriados ao tipo de credencial usado. Para tokens de usuário do sistema, utilize os controles de usuários do sistema do portfólio empresarial. Não compartilhe o token ao solicitar ajuda.

3. Remova as cópias salvas

Exclua relatórios, exportações, arquivos temporários e registros locais que contenham os dados a remover. Remova também conversas e arquivos correspondentes no cliente de IA, conforme as opções do serviço. Verifique cópias adicionais que tenham sido salvas ou compartilhadas.

4. Solicite auxílio

Envie um e-mail a ggfernandess@gmail.com com o assunto “Ads Ops Hub — exclusão de dados”. Identifique a conta ou o conjunto de dados envolvido e explique o que deseja remover. Não inclua senhas, tokens nem dados de terceiros desnecessários.

A exclusão de credenciais e cópias do Ads Ops Hub não exclui campanhas, anúncios, leads ou outros dados armazenados pela própria Meta.
